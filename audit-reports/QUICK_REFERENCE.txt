6. FINANCE EXPENSES PIB BREAKDOWN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When expense_category = 'pib_import', must provide:

  pib_bm_amount      ← Import duty, goes to inventory landed cost → Account 1130
  pib_ppn_amount     ← PPN input tax, posted to PPN Masukan → Account 1150
  pih_pph_amount     ← PPh 22 advance, posted to PPh 22 Prepaid → Account 1155

Constraint: chk_pib_breakdown_sum
  pib_bm_amount + pib_ppn_amount + pib_pph_amount ≈ amount (within ±1.00)

Journal Entry Created (4 lines):
  Line 1: DR 1130 (Inventory)      pib_bm_amount
  Line 2: DR 1150 (PPN Input)      pib_ppn_amount
  Line 3: DR 1155 (PPh 22 Prepaid) pib_pph_amount
  Line 4: CR Bank/Cash             (total amount)

Function                                   Purpose

                                          balance (9 columns per row)

Columns returned by all reporting functions:
  • code (VARCHAR) - Account code like "1101"
  • name (VARCHAR) - English account name
  • name_id (VARCHAR) - Indonesian name
  • account_type (VARCHAR) - asset|liability|equity|revenue|expense|contra
  • account_group (VARCHAR) - For section grouping
  • normal_balance (VARCHAR) - debit|credit
  • total_debit (NUMERIC) - Sum of debits
  • total_credit (NUMERIC) - Sum of credits
  • balance (NUMERIC) - debit - credit (can be negative)
